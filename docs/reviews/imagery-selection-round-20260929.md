# Bounded imagery selection development round

Reference: merged Sentinel-2 foundation `7546d0839a254dbe8d7dc180adc3ca3b709d6048`. This stage adds an operator workflow for explicit, reproducible scene selection. Existing app controls, source preprocessing recipes, runtime corpus and training authority remain unchanged.

## Contract and shared implementation

A metadata-only plan freezes one provider, polygon, date interval, up to eight scene identities (default three), processor version and a task-specific index/support/minimum-valid-fraction policy. One date-descending STAC page is retained by identity; pagination and replacement search are prohibited. Scene-cloud metadata is descriptive. HLS S30/L30 support field polygons; Sentinel-2 also supports interior statistics. Each run reuses the existing source processors and integrity-indexed chip store.

Selection uses valid index area divided by full chosen support area. It rejects empty support, zero index coverage and fractions below the explicit threshold; missing or contradictory QA is unavailable, not zero. Eligible candidates rank by fraction, acquisition recency and scene ID. Index magnitude never ranks candidates. Any unknown or unprocessed candidate leaves an incomplete decision and no winner; observed rankings and every failure remain inspectable. Thus a failed older candidate cannot silently justify selecting the newest available scene.

Request, geometry, provider, collection, scene, acquisition time, processor and chip/process identities must agree. The plan freezes candidate identity and recipe, not immutable remote assets: actual validated source metadata belongs to the existing chip receipt. Integrity hashes are self-checks, not authenticity signatures. A stable decision hash excludes attempt-specific timing, cache hits and transfer counts, which remain bound by the full receipt hash. No second raster cache is introduced.

Shared COG accounting reserves capacity across concurrent range readers, totals failed and successful application-consumed payload, counts outbound attempts, and refuses publication after a quota violation. Per-invocation, per-scene and existing storage budgets are distinct. These are application payload/request limits, not a wire-traffic meter or whole-job deadline. The CLI defaults offline, reserves a new private output before egress, and never overwrites an earlier result.

## Evidence and qualifications

Analytic and metamorphic tests cover explicit policies, selected-index versus QA coverage, empty interiors, zero denominators, malformed plans, unknown candidate preservation, deterministic ties, index-magnitude independence, source identity and all three provider dispatches. Real local HTTP tests exercise shared concurrent budgets, failed reads, per-scene limits and request exhaustion. An actual raster/processor/cache seam verifies that a cloudier latest scene loses to older usable coverage, that a larger index value cannot win a tie, and that corrupt cached arrays prevent complete offline selection.

The original five seed-20260928 research AOIs and date windows were reused without replacement. All five geometries were independently reproduced exactly from published USDA-ARS CC0 coordinates: convex hull plus 15 m working-UTM buffer. [Official metadata](https://catalog.data.gov/dataset/data-from-topographic-position-index-predicts-within-field-yield-variation-in-a-dryland-ce) establishes public access and licensing. These are sampled support hulls with an unresolved original datum, not surveyed field boundaries. No yield labels or private field records were transmitted or admitted into runtime/training.

The frozen example policy required 80% valid interior NDVI with 60 m cloud and 20 m interior margins. All five metadata plans were frozen before new pixel reads. The two 2019 AOIs each returned three candidates; all six candidate chips had 100% valid interior NDVI under the existing masks, so recency selected the latest candidate in both. The three original 2022 queries returned empty pages and remain `no_scene`. Each populated AOI consumed 15,761,408 COG application bytes and 63 requests, under the frozen 32 MiB/160-request cap, and completed within its externally enforced 180-second limit. All five exact offline replays retained their decision hashes. This live sample exercises ties and source/cache integration; it does not demonstrate cloud rejection quality. Controlled raster tests exercise differing coverage and rejection.

The previous temporary imagery environment and chips were absent when this stage began; they were not claimed as available replay evidence. A new isolated environment and fresh bounded acquisitions supplied this round. Prior receipts and the initial missing-interpreter failure remain retained. Automatic network review initially rejected the public geometries as sensitive; exact public-source derivation evidence resolved the assumption before the successful retry. Precise geometries, raw metadata/pixels and local receipts remain outside the public package.

## Independent-review repair

Review reproduced an HTTPX failure-accounting gap: a connection could truncate before a complete 16 KiB iterator chunk, causing consumed bytes to disappear from the yielded-chunk counter. Five partial responses consumed 40,960 bytes while the initial invocation counter reported zero. The repaired transport reconciles HTTPX's actual downloaded-byte counter before releasing reservations, including buffered tails after exceptions or downstream interruption. Real default-chunk regressions cover a wholly buffered partial body and a complete chunk plus partial tail under both batch and per-scene caps; these supplement the original small-chunk concurrency controls. Test doubles now expose the same response counter as HTTPX. The failed probe remains preserved. This changes failure accounting, not source radiometry, masks, cache identity or selection policy.

## Remaining stages

Coverage screening does not prove cloud-free observations, correct aerosol retrieval, crop-only support, geolocation accuracy, cross-sensor comparability or field response. The bounded latest page can miss a better older scene and introduces seasonal/cloud missingness bias. Water remains included by the existing clear-class policy. Registration on surveyed boundaries, common-support temporal comparisons, baseline/sensor effects and separately identified 10 m products remain later work. No imagery-derived field action is authorized by a selected receipt.
