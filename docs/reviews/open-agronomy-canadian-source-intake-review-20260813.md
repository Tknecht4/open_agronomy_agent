# Canadian source-intake review — initial Alberta and Manitoba documents

**Status:** Alberta documents reviewed in this pass remain outside the distributable store; two Manitoba guides have hash-bound, semantic-only context companions in the latest immutable candidate store

**Review date:** 2026-08-13
**Scope:** source identity, licence evidence, document content, geographic applicability, and safe-RAG fit. This is not a legal opinion, a current regulatory interpretation, or agronomic advice.

## Intake rule used

An official, open-licence catalogue record is necessary but not sufficient for admission. A source also needs a frozen raw-byte identity, an applicable and enforceable geographic scope, reviewed extraction boundaries, current-authority limits where applicable, and an explicit `training: false` decision. The raw PDFs and catalogue responses are retained outside Git under a user-controlled intake directory; this repository contains only the review and future policy contracts.

## Why the Bow River source is not yet ingested

Current Canadian RAG filtering structurally understands country/province jurisdiction, not a watershed or plan-area boundary. Marking this document as `jurisdiction: ["Alberta"]` would allow a phosphorus query from elsewhere in Alberta to retrieve it. The guide itself says BMP selection depends on local soil, climate, crop management, and site factors; it also directs regulated decisions to current Alberta authorities. Those are material scope limitations, not boilerplate.

The [official Alberta plan page](https://www.alberta.ca/bow-river-phosphorus-mangement-plan) describes the managed reach narratively, and the older official [plan record](https://open.alberta.ca/api/3/action/package_show?id=ecb82323-c147-4eba-83e6-ca9838ca6f30) contains a static plan-area figure. Neither supplies a verified, reusable plan-area geometry or a reproducible inclusion rule. The published narrative includes only *part* of named irrigation-district lands/canals, so watershed, municipality, district, tributary, dam-line, and centroid proxies would all risk false inclusion. An exact-name search of Alberta GeoDiscover’s public catalogue returned no record; that is a bounded negative check, not proof that no geometry exists elsewhere.

The document therefore remains outside `canada_agronomy_sources.json`, the source-shard directory, and every curated-store profile. Its official catalogue record establishes a reuse lead, but the document’s Alberta wordmark and uncredited embedded visual material still require text-only, source-specific review before any derivative is bundled.

## Manitoba semantic-only candidate sources: what entered the latest store

The two Manitoba guides were eligible for a narrower path because their declared geography is the Province of Manitoba, which the current retrieval boundary can enforce. Their governed source records are `mb_2026_crop_disease_scouting` and `mb_2023_crop_rotation_context`; both pin the raw PDF hashes above, use `context_only`, and have `training: false`. The disease guide additionally sets `regulated_advice` and `require_live_authority` to true. The rotation note carries a historical-currency tag because its underlying observations are not current field predictions.

Each real source-shard intake used the staged, hash-verified PDF and wrote four companion-only rows plus a source receipt. The resulting `curated-canada-v3` extended profile contains 960 rows in three policy-segregated shards. The two additions account for eight rows, all `context_only`. Cache-free retrieval checks admitted the canola/clubroot and field-history/emergence contexts for Manitoba fields and rejected Alberta controls as `jurisdiction_mismatch`; unsafe-term checks found no product, rate, threshold, unit, MASC, table, visual, or crop-specific leakage in the rotation records.

This is a candidate profile, not a silent replacement for the currently configured legacy runtime. Its narrow source decisions do **not** grant pesticide, label, compliance, sanitation-procedure, timing, rate, diagnosis, field prediction, or field-prescription authority. Before any default-profile promotion, the legacy Manitoba disease companions need their own separate source/policy audit and the generated v3 RAG/policy files need the normal active-config, public-manifest, and regression gates. In particular, the revised disease rows reuse legacy Manitoba semantic document IDs, so a future activation must switch profiles and exclude the legacy supplemental corpus—not append another corpus path. The signed knowledge-update path now resolves profile-local artifact roots and successfully packages/validates the v3 candidate unsigned; it still requires the normal signing and release decision for deployment.

## Admission path for the Bow River guide

Admission may proceed only after all of the following are independently true:

1. Freeze an owner-published/endorsed Bow River Plan-area geometry or an explicit reproducible inclusion definition, its licence, byte/hash identity, effective date, and an inside/outside routing test. A text label or static map figure alone is insufficient.
2. Carry that geographic applicability into retrieval and test that an out-of-area Alberta field cannot retrieve the source.
3. Create a manually reviewed semantic companion rather than raw-PDF chunks. It may retain qualitative context about runoff pathways, representative soil testing, field-risk assessment, ground cover/riparian condition, and livestock-access considerations.
4. Exclude logos, photos, diagrams, legal/setback figures, numeric rates/thresholds/depths/frequencies, permits, AOPA/CFO requirements, and field-specific prescriptions. Answers using the source must direct current requirements and consequential field decisions to current provincial authority and local evidence.
5. Pin the raw PDF SHA-256 in the governed source record; run external source-shard extraction; inspect every emitted row and receipt; then create a new immutable curated-store version and explicit profile selection. Do not edit `curated_canada/v1` in place.
6. Keep `training: false` unless a separate source-specific training authorization and provenance review is approved.

## Falsifiers and next selection rule

The conditional decision changes to rejection if an official boundary cannot be identified, its licence does not support the intended derivative, or retrieval cannot enforce its scope. It changes to active source admission only after the six gates above pass. Until then the only safe geographic activation is manual confirmation by a plan owner, never inference from a field coordinate. The next documents prioritized for review should either be province-wide, clearly crop/region scoped in a way the runtime already enforces, or arrive with an admitted spatial boundary contract. Public accessibility and an open catalogue entry alone do not satisfy that rule.
