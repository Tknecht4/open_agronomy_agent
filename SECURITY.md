# Security policy

## Report a vulnerability

Use GitHub's [private vulnerability report](https://github.com/Tknecht4/open_agronomy_agent/security/advisories/new). Include the affected commit or version, impact, a minimal reproduction, and a suggested fix if known. Do not put exploit details, credentials, private farm data, or precise field locations in a public issue, Discussion, or pull request. If the private-report option is unavailable, [ask in Discussions](https://github.com/Tknecht4/open_agronomy_agent/discussions) for the reporting channel to be enabled, without describing the vulnerability.

The maintainer will assess reports as capacity allows. There is no promised response or remediation SLA. Please allow time for a fix and coordinated disclosure before sharing details publicly.

## Scope

The current default branch is a development target, and the Apple Silicon desktop app is a candidate rather than a qualified, notarized release. Historical artifacts, experimental profiles, and third-party packages are not promises of supported deployment. Security fixes should include a regression check where practical and distinguish a code defect from unverified agronomic behavior. See [SUPPORT.md](SUPPORT.md) for ordinary bugs and questions.
