---
name: evaluation-evidence
description: Analyze Open Agronomy evaluation evidence or change its scoring and harness contracts while preserving source identities, unknowns and controller-only references.
---

Use `scripts/analyze_release_evaluation.py --inventory` to locate the maintained
execution surfaces before choosing a runner. The canonical product suite is
`scripts/run_release_evaluation.py`; its `--dry-run` inspects a plan without
inference. Read [the operator guide](../../../docs/public/operations/release-evaluation.md)
for current inputs and dispositions. A source inventory is not a test result.

For retained analysis, bind original case, answer, rubric, model/config, arm and
runtime identities. Keep the original run immutable and create a new derived
output directory. Use the existing analyzer rather than a second scoring CLI.
Do not replace historical lexical grades with semantic quality labels.

Separate useful completion, restraint, numeric/unit accuracy, evidence support,
applicability and tool correctness. Unknown labels retain their denominator;
manual arithmetic and a required tool failure are different observations.
Weights are explicit project choices. Compare only recorded matching facts,
criterion masks and cohorts; report missing identities instead of inferring them.

For the ten exposed development domains, the operator guide supplies provisional
`configs/model_scoring_development_v1.json` and a synthetic worked CLI example.
Freeze policy/rubric bytes before a future authorized run; retrospective hash
binding is not preregistration. Read per-domain/criterion results, unknown bounds,
execution penalties and safety counts before a composite. A complete synthetic
score grants no ranking or promotion authority.

Keep references, oracles, rubrics and expected decisions in the controller.
Verify the actual `release_evaluation.worker_case` projection before admitting
new cases. Synthetic fixture labels check the instrument; they are not expert
grades. Development exposure and unresolved study overlap remain visible.

Read timing states and scopes before comparing performance. A skipped zero
prefill span is unmeasured, a first-token timer may exclude loading, and unequal
output lengths do not establish an inference speed regression. Device, precision,
warmup/cache and remote-service unknowns cannot become matched conditions.

Run focused instrument, lineage and worker-isolation checks for the changed
contracts. Report executed observations separately from feedback summaries,
review coverage and promotion gates. Preserve failed and interrupted evidence.
