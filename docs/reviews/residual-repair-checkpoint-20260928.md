## Scope and acceptance

The owner repairs verifier quantity/polarity handling and audit attribution.
Two bounded workers implement task-scoped METHOD selection and model residency.
The whole-phase estimate is 60–100 minutes including integration, independent
Astra review and up to two repair loops; provider token/currency totals are
unavailable. One public-data L4 regression has a 45-minute checkpoint. If that
estimate is exceeded, optional expansion stops and the smallest defensible
checkpoint is reassessed. No model weights are loaded on the laptop.

| Obligation | Repair and decisive check |
| --- | --- |
| Numeric identity and relation | Complete quantities include signs, separators, ranges and units; a bounded container mass total requires explicit unambiguous premises. Regression cases cover substring errors, wrong reused totals, conflicting premises and action permission. |
| Diagnostic polarity | A negative diagnosis needs explicit source exclusion; a mentioned organism alone does not confirm a field diagnosis. Positive and negated controls remain distinct. |
| Completion | A terminal numeric sentence is separate from an empty numbered list item. |
| Audit attribution | Version 2 records answer-level triggers separately from changed sentences with located lexical triggers. Evidence IDs identify review context, never claim-level proof. |
| Method selection | A typed question task frame feeds obligations and card admission; background, negated and unresolved mentions do not automatically select methods. Applicability and source authority gates remain intact. |
| Model residency | One target/draft pair is retained; public operations release generator references. A pair switch clears old KV namespaces and cannot evict a leased pair. |
| Integration | Focused and full tests, public docs/build/package checks, bounded real-backend regression, source-bound independent review, CI and verified main merge. |

## Limits retained

Quantity matching remains screening rather than general semantic entailment.
Only a single question phrase explicitly binding container count and
per-container mass is derived in this checkpoint; other arithmetic requires typed calculation evidence. An accepted
quantity does not authorize a rate, diagnosis or operation. Broader route-content
rules can still trigger review of a cautious diagnostic answer.

METHOD parsing is a bounded deterministic language parser, not demonstrated
cross-model general agronomic expertise. The candidate corpus stays inactive.
A single retained model pair bounds Python ownership, not allocator/transient
GPU memory or laptop fit. Alternating target/editor models may require reloads.
The numerical cause of cache divergence remains unresolved and active prompt
caching stays disabled. No 27B Metal/laptop qualification is asserted.
