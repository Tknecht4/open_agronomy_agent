## What the design can identify

The six strata contain four selected cases each, not a prevalence sample. Nineteen questions reuse the exposed successor suite, one reuses the exposed field-data pilot, and four correction histories are newly authored but related to repository examples (`cohort/README.md`; `cohort/manifest.json`). Thus a score change is a change on these frozen tasks, with possible case exposure and rubric alignment; it is not a generalization or user-helpfulness estimate. A task-completion regression can coexist with a safe, useful answer that omits an unasked checklist item. Conversely, a complete rubric score does not by itself prove source authority or field-action safety; material errors and justified uncertainty must be read separately.

The evidence labels show seven `active_source_present` cases (`sv24-01`, `04`–`07`, `16`, `21`), two named-source-absent cases (`02`, `15`), and two with an active source but critical field inputs missing (`20`, `24`). The rest chiefly test supplied arithmetic, private-table setup, direct observations/records, general principles, or missing authority. Therefore a pooled 24-case document/graph contrast mixes source-dependent opportunities with tasks that retrieval cannot complete on its own. `sv24-02` and `15` can test bounded general reasoning despite absent named Ontario guidance, but cannot establish that the active retriever supplied that guidance. `sv24-13` and `14` similarly provide the decisive field observation or record in the question while source-specific specifications are absent. `sv24-08` is interpretable as a table task only after its reviewed private import; setup failure must remain separate from answer quality. No case-level graph-specific necessary fact is marked in these frozen files, so a graph-only gain or loss cannot be attributed to graph knowledge from the pooled score alone.

For a **new**, pre-registered setup, freeze each question's minimal answer obligation, optional helpful additions, material-error and action-authority checks as separate fields; bind every required item to a question phrase or justified safety need. Include source availability *per arm and execution*, and label whether the answer requires admitted document facts, graph relationships, supplied user facts, private imported data, or current external authority. Keep source-absent, source-present, and missing-input cases separate; report all-attempt denominators, failures, timeouts, and length stops. Use fresh source-distinct cases for any generalization decision and independent agronomic review for consequential claims. This proposal is prospective only; the 24-case scores and rubric identities remain frozen.
