# Code of Conduct

This project welcomes constructive, evidence-based participation. Treat people respectfully. Critique ideas, code, claims, and evidence without personal attacks. Avoid harassment, discrimination, threats, doxxing, sexualized attention, and repeated unwanted contact. Respect privacy when discussing farms, fields, contributors, and users.

These expectations apply to issues, Discussions, pull requests, reviews, and other project spaces. The maintainer may edit or remove harmful content, ask participants to stop, limit participation, or block an account. Decisions will consider context and the safety of affected people.

For a public conduct concern, use the [community concern form](https://github.com/Tknecht4/open_agronomy_agent/issues/new/choose) with a minimal, non-sensitive description. Do not post private messages, identifying details, or sensitive evidence there. GitHub's own reporting and blocking tools are available for abuse. The project does not currently provide a confidential conduct-reporting channel. Vulnerability reporting in [SECURITY.md](SECURITY.md) is for security issues, not conduct reports.
